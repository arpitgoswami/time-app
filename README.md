# Time App

A lightweight, real‑time clock application built with modern web technologies.

## Overview
Time App provides an elegant, responsive clock that displays the current time locally without requiring any external APIs. It runs entirely client‑side, making it fast and privacy‑friendly. The interface is crafted with Tailwind CSS for a clean, mobile‑first design, while the logic is written in vanilla JavaScript.

## Features
- **Live Clock** – Shows the exact local time updated every second.  
- **Responsive Design** – Adapts seamlessly from desktop to mobile screens thanks to Tailwind’s utility classes.  
- **Customizable Theme** – Switch between light and dark modes via a simple toggle.  
- **No External Dependencies** – Pure HTML, CSS, and JavaScript; perfect for static hosting.  
- **GitHub Pages Deployment** – Automatically served from the repository for easy sharing.

## Technology Stack
- **HTML5** – Semantic markup for the UI.  
- **JavaScript (ES6+)** – Core logic for time calculation and DOM manipulation.  
- **Tailwind CSS** – Utility‑first styling for rapid, consistent design.  
- **Git & GitHub** – Version control and source management.  
- **GitHub Pages** – Static site hosting.
